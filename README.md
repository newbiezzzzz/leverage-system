## Decision rule

New ideas are alternatives, not automatic replacements.

A directional change requires evidence that the current approach cannot meet the objective, a material constraint change, or an explicit Owner decision.

The automated decision-governance workflow fails closed when mission direction drifts away from the persistent decision record.

## Owner interaction

The Owner should primarily communicate through ChatGPT. The repository holds the persistent project truth so future sessions do not depend on conversational memory alone.
