# P-001 Gumroad → Public Web CTA

## Goal
Every Gumroad visitor should have a clear, clickable path into Leverage's public web acquisition surface.

## Destination
https://leverage-tools.pages.dev/fabrication-quote-calculator/?utm_source=gumroad&utm_medium=product&utm_campaign=p001&utm_content=free-calculator

## CTA label
**Try the FREE Fabrication Quote Calculator**

## Placement
Place the CTA near the top of the Gumroad product description, before the feature list.

## Buyer flow
`Gumroad product -> Free Fabrication Quote Calculator -> Leverage public web -> product discovery -> Gumroad purchase`

## Safety boundary
This update changes only the Gumroad listing description/CTA. It does not change price, payout settings, payment credentials, account security, or money movement.

## Verification
The local browser worker must verify:
- the CTA label is visible;
- the destination URL is present;
- the destination is a clickable link;
- the public Gumroad listing remains accessible after the edit.
