# Public Site Factory

Every product can generate a public acquisition surface without becoming a low-quality content farm.

## Page types

- product landing page
- free tool page
- educational guide
- comparison/decision page
- FAQ/support page
- category hub

## Required page pipeline

`research -> information architecture -> visual design -> implementation -> functional QA -> responsive QA -> creative QA -> conversion QA -> SEO metadata -> deploy -> telemetry`

## Creative requirement

The design pass is mandatory. The system must evaluate composition, hierarchy, typography, spacing, imagery, responsive behavior, accessibility and CTA clarity separately from functional correctness.

## Content requirement

Content should answer a real user question or demonstrate a real use case. Do not mass-publish near-duplicate pages merely to increase URL count.

## Acquisition loop

`search/social discovery -> useful page/tool -> product education -> product page -> marketplace/store -> measurement -> improvement`
