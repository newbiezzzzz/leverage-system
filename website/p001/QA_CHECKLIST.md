- [ ] Gumroad CTA opens the P-001 product URL.

- [ ] FAQ disclosures open/close.

- [ ] CTA is visually dominant without deceptive urgency.
- [ ] No fake testimonials, reviews, sales or guarantees.

## Accessibility
- [ ] Page has one H1.
- [ ] Section headings are ordered logically.
- [ ] Links are keyboard reachable.
- [ ] Text remains readable with increased zoom.
- [ ] Color contrast remains usable.

## Conversion
- [ ] Product evidence appears before final CTA.
- [ ] Buyer problem is explicit.
- [ ] Product scope/boundaries are explicit.
- [ ] Price is visible and matches current listing.
- [ ] Direct product URL is authoritative.

## Release rule
Minimum creative/conversion score: 85/100. Any failed critical item blocks production release until corrected.
